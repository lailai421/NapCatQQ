# 常用命令

- 安装依赖：`pnpm install`
- 类型检查：`pnpm typecheck`
- 测试：`pnpm test`
- Lint：`pnpm lint`
- 自动修复 Lint：`pnpm lint:fix`
- 开发 shell：`pnpm dev:shell`
- 构建 shell：`pnpm build:shell`
- 构建 framework：`pnpm build:framework`
- 构建 WebUI：`pnpm build:webui`
- 构建内置插件：`pnpm build:plugin-builtin`
- 构建 OpenAPI：`pnpm build:openapi`
- 系统检索优先使用：`rg`、`rg --files`。
